# POE 카카오 자동 로그인 (크롬 확장)

`poe.kakaogames.com` 접속 시 매번 반복하던
**로그인 → 카카오 로그인 → 저장된 카카오 계정 선택** 3번의 클릭을 자동으로 처리합니다.

비밀번호는 저장하지도, 입력하지도 않습니다. 브라우저에 이미 남아 있는
카카오 "간편로그인" 항목을 대신 클릭해 줄 뿐입니다.

## 설치

1. 크롬 주소창에 `chrome://extensions` 입력
2. 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드** 클릭
4. 이 폴더(`KakaoAutoLogin`) 선택

5. 툴바의 확장 아이콘을 눌러 팝업을 열고, **설정** 탭에 **본인의 카카오 계정 이메일**을 입력

> 아이콘이 안 보이면 툴바의 퍼즐 조각 아이콘 → 핀 모양을 눌러 고정하세요.

### 처음 설치하면 계정이 비어 있습니다

미리 설정된 계정은 없습니다. 계정을 입력하기 전에는 자동 로그인이 **아무 동작도 하지 않고**,
아이콘에 노란 `?` 배지와 함께 "설정 필요" 안내가 뜹니다.
카카오 계정 선택 화면에 보이는 이메일(예: `내아이디@kakao.com`)을 그대로 적어주세요.

입력한 계정은 이 크롬 프로필 안에만 저장되며(크롬 동기화 저장소), 파일에는 들어가지 않습니다.
그래서 폴더를 다른 사람에게 그대로 줘도 내 계정이 따라가지 않습니다.

## 팝업 (툴바 아이콘 클릭)

| 탭 | 내용 |
|---|---|
| **상태** | 마지막 로그인 성공/실패와 실패 사유, 계정, `게임 시작`, `거래소 열기`, 최근 실행 로그 |
| **설정** | 카카오 계정 이메일, 단계별 대기 시간, 재시도 한도, 거래소 History 버튼, 새 판매 배지 알림 (입력하면 바로 저장) |
| **도움말** | 확장이 하는 일, 캡챠 화면 안내, 안 될 때 확인할 것 |

- `게임 시작`은 `pathofexile2.kakaogames.com/main`을 열고, 공지 팝업을 `오늘 하루 그만 보기`로 닫은 뒤
  (필요하면 로그인하고) 메인의 `게임 시작` 버튼까지 눌러줍니다. 팝업 버튼으로 들어왔을 때만 누르며,
  런처 실행 확인창은 브라우저 창이라 처음 한 번 직접 `항상 허용`해야 합니다.
  자동 클릭은 사용자 클릭이 아니어서 사이트가 여는 창이 팝업 차단에 걸리므로,
  확장이 `contentSettings` 권한으로 `pathofexile2.kakaogames.com`의 팝업 및 리디렉션만 `허용`으로 설정합니다.
- 웹 거래소(`poe.kakaogames.com/trade2`) 우측 상단 `설정` 옆에 `History` 버튼을 붙입니다.
  `/api/trade2/history/<리그>` 판매 내역(최대 100건)을 아이템명 · 가격 · 경과 시간으로 보여주고,
  아이템명에 마우스를 올리면 옵션 툴팁이 뜹니다. 리그는 현재 거래소 URL에서 읽습니다.
  (사이트가 메뉴 DOM 을 다시 만들기 때문에 버튼 클릭은 document 캡처 단계에서 위임 처리합니다.)
  설정 탭에서 끌 수 있으며, 끄면 버튼을 붙이지 않고 API 도 호출하지 않습니다.
- **새 판매 배지 알림**(기본 꺼짐)을 켜면 background 가 `chrome.alarms` 로 **30분에 1회** history API 를 호출해
  마지막으로 History 창을 연 뒤 새로 팔린 개수를 아이콘 배지(빨간 숫자)로 보여줍니다.
  확인할 리그는 마지막으로 History 를 연 리그이고, History 를 다시 열면 0이 됩니다.
  같은 숫자가 거래소 History 버튼 좌측 상단에도 뜨고, History 창에서는 지난번 확인 뒤 팔린 행에 빨간 `NEW` 가 붙습니다.
  429 / 레이트 리밋 헤더를 받으면 그 시간 동안 확인을 쉬며, 로그인 실패 `!` · 설정 필요 `?` 배지가 숫자보다 우선합니다.
- 상단 스위치로 자동 로그인을 잠깐 껐다 켤 수 있습니다.
- 실패해서 `!` 배지가 뜨면 팝업 상태 탭에 **이유가 한국어로** 표시되고,
  `다시 시도할 수 있게 초기화` 버튼으로 바로 풀 수 있습니다. (콘솔을 열 필요 없음)
- 계정이 비어 있으면 노란 `?` 배지가 뜨고, 상태 탭에 `설정 탭에서 계정 입력하기` 버튼이 보입니다.
- 테마는 윈도우의 밝은/어두운 모드를 자동으로 따라갑니다.

## 동작 방식

| 단계 | 페이지 | 확장이 하는 일 |
|---|---|---|
| 1 | `poe.kakaogames.com` (로그아웃 상태 / 로그인 오류 페이지) | 우측 상단 **로그인** 버튼 클릭 |
| 2 | `member.kakaogames.com/login` | **카카오 로그인** 버튼 클릭 |
| 3 | `accounts.kakao.com` | 설정한 이메일이 적힌 계정 항목 클릭 |
| 4 | 로그인 완료 후 | 원래 가려던 주소(`redir` 파라미터, 예: `/trade2`)로 이동 |

버튼은 클래스명이 아니라 **화면에 보이는 글자**로 찾기 때문에, 사이트 디자인이
조금 바뀌어도 대체로 계속 동작합니다.

## 안전장치

- `accounts.kakao.com` 은 모든 사이트가 공유하는 카카오 로그인 도메인이므로,
  **카카오게임즈 로그인 플로우일 때만** 자동 클릭합니다.
  (다른 서비스의 카카오 로그인 화면에서는 아무 동작도 하지 않습니다.)
- 계정 목록의 **삭제(×) 버튼은 절대 클릭하지 않습니다.**
- 같은 단계가 반복되면(기본 3회) 자동 진행을 멈추고
  확장 아이콘에 빨간 `!` 배지와 크롬 알림으로 "수동 로그인 필요"를 알립니다.
  → 무한 새로고침 루프가 생기지 않습니다.
- 중단된 상태는 옵션 화면에서 **저장**을 누르면 초기화됩니다.

## Cloudflare 보안 확인(캡챠)이 뜰 때

가끔 접속 전에 Cloudflare의 **"사람인지 확인하십시오"** 체크박스가 뜹니다.
이건 확장이 대신 눌러주지 않습니다 (봇 감지 우회는 하지 않습니다).
**체크박스만 직접 한 번 눌러주시면** 페이지가 다시 로드되면서 자동 로그인이 이어서 진행됩니다.

확장은 이 화면을 인식해 아무 동작도 하지 않으므로, 재시도 횟수도 소모되지 않습니다.
(같은 안내가 팝업의 **도움말** 탭에 그림과 함께 들어 있습니다.)
단, 이 화면에서 2분 이상 머무르면 진행 중이던 플로우가 만료되어
`/trade2` 대신 메인 페이지로 로그인될 수 있습니다. 그때는 주소만 다시 입력하시면 됩니다.

## 문제가 생기면

1. 해당 페이지에서 `F12` → Console 탭 → `KakaoAutoLogin` 으로 필터
2. 어느 단계에서 멈췄는지 로그로 확인
   (`인식할 수 있는 로그인 요소가 없음`, `설정한 계정을 찾지 못했습니다` 등)
3. 계정 이메일 오타 여부를 팝업 **설정** 탭에서 확인
4. 팝업 **상태** 탭의 `로그 보기` 로 최근 단계 기록 확인

## 문의 · 건의

오류 제보나 기능 건의는 [카카오톡 오픈채팅](https://open.kakao.com/me/iammove)으로 보내주세요.
팝업 상태 탭 아래 `문의 · 건의` 링크와 도움말 탭의 `문의하기` 버튼으로도 열 수 있습니다.

## 참고

재부팅할 때마다 로그인이 풀리는 건 카카오 세션 쿠키가 브라우저 종료와 함께
사라지기 때문입니다. 크롬 설정의 **"중단한 위치에서 계속하기"** 를 켜두면
세션 쿠키가 유지되어 이 현상 자체가 줄어들 수 있습니다.
